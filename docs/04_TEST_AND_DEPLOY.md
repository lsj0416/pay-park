- 320px, 375px, 390px, 430px 너비에서 가로 넘침이 없다.
- S01~S04 단계 탭은 가로 스크롤되고 현재 단계가 보인다.

## 계산 단위 테스트

```js
console.assert(calculateBudget({
  income: { basis: "gross", grossSalary: 3200000 },
  deductions: {
    fixedExpenseItems: [{ amount: 700000 }, { amount: 50000 }, { amount: 20000 }],
    savingItems: [{ amount: 500000 }],
  },
}).availableAmount === 1505870);

console.assert(calculateDailyBudget(1505870, "2026-09-09", new Date("2026-08-12")).dailyBudget === 51927);
```

- 빈 문자열, 쉼표 포함 문자열, 음수, 소수, 매우 큰 값 처리
- `basis === "net"`일 때 4대보험·소득세 계산을 건너뛰고 입력값을 그대로 실수령액으로 사용하는지
- `buildPlan()` 배분 금액 합(`goals` 합 + `remainingLiving`)이 `availableAmount`와 정확히 일치
- 금액을 특정할 수 없는 문장 입력 시 목표 자금 30% 기본값으로 폴백
- 월말 28·29·30·31일 보정(월급일 30일 프리셋 + 2월)

## Netlify 배포

### 가장 빠른 방법

1. 프로젝트 폴더에서 `index.html`이 루트에 있는지 확인한다.
2. Netlify Drop에 폴더 또는 zip 파일을 업로드한다.
3. 생성된 URL을 모바일 브라우저에서 확인한다.

### Git 연동 시

- Build command: 비워 둠
- Publish directory: `.`

선택적으로 다음 파일을 둘 수 있다.

```toml
# netlify.toml
[build]
  publish = "."

[[headers]]
  for = "/*"
  [headers.values]
    X-Content-Type-Options = "nosniff"
```
