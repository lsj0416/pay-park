# 이번달페이 HTML 프로토타입 개발 문서

## 한 줄 정의

이번달페이는 월급에서 예상 세금·고정비·저축을 빼고 **이번 달에 실제로 쓸 수 있는 돈**을 계산한 뒤, 사용 목적에 맞춘 활용 계획과 저축상품 후보를 보여주는 비회원 프로토타입이다.

## 최종 구현 기준

- 디자인 기준: Figma `유경` 페이지
- 구현 방식: `HTML + CSS + Vanilla JavaScript`
- 배포 방식: Netlify 정적 배포
- 인증·서버·데이터베이스: 사용하지 않음
- 저장: 브라우저 `localStorage`
- AI: 외부 API 없이 규칙 기반 응답으로 시연
- 화면: 7개이며, 별도의 마이페이지는 만들지 않음

## 문서 구성

| 문서 | 용도 |
| --- | --- |
| `00_PRODUCT_AND_FLOW.md` | 제품 범위, 7개 화면, 사용자 흐름 |
| `01_DATA_STATE_CALCULATION.md` | 공용 데이터, 계산식, 저장 규칙 |
| `02_UI_COMPONENTS.md` | UI 토큰, 공통 컴포넌트, 접근성 |
| `03_FEATURE_SPEC.md` | 화면별 입력·출력·행동 명세 |
| `04_TEST_AND_DEPLOY.md` | 테스트 기준과 Netlify 배포 |
| `05_ORCHESTRATION_TASKS.md` | AI 병렬 작업 분담과 통합 순서 |

## 우선순위

1. 기간·소득·고정비/저축 입력과 가용 자금 계산
2. 입력값과 결과의 자동 저장·복원
3. AI 활용 계획 시뮬레이션과 상품 후보 노출
4. 결과가 반영된 홈 대시보드
5. 모바일 화면 QA와 정적 배포

## 완료 정의

- 첫 방문자는 홈 CTA로 계산을 시작할 수 있다.
- 3단계 입력 후 같은 값으로 항상 같은 가용 자금이 계산된다.
- 새로고침해도 입력과 완료 결과가 유지된다.
- 단계 탭으로 이전 입력을 다시 확인하고 수정할 수 있다.
- AI 계획을 적용하면 반영 결과와 홈 대시보드가 갱신된다.
- 모든 기능이 서버 없이 Netlify URL에서 작동한다.
